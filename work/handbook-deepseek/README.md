# DeepSeek に渡す教材パック

作成日：2026年11月6日（日本時間）  
対象：設計・開発課 管理／現行 V2 フロントエンド／MANAGER・MEMBER

## 渡すもの

1. `01_DEEPSEEK_PROMPT.md` の全文を DeepSeek に貼り付けます。
2. `02_HANDBOOK_JA.md` と `03_AUTHORING_SPEC.md` を添付します。
3. `images/` の PNG を添付します。画像を認識できない環境なら、章ごとに該当画像をアップロードします。
4. 出力された Markdown は、このフォルダーと同じ画像構成で保存します。

ZIP を読めないサービスには展開して渡してください。DeepSeek にこの PC のローカルパスだけを渡しても画像は見えません。

## このパックの位置付け

- 日本語の利用手順原稿、章構成、画像指定、編集指示をまとめた制作素材です。
- 画像は**現在の作業ツリーの実際の React UI を、架空の API 応答で表示したもの**です。MANAGER/MEMBER の表示を分けています。
- 旧ナビゲーションの画像や ADMIN の画像は採用していません。
- 本番環境へのログイン、データ変更、削除、送信、承認、公開は行っていません。
- 画像は配置・ラベルの確認用です。架空データの集計値、期限、階層や状態の整合性を本番の動作保証に使わないでください。
- 現在の作業ツリーには未コミットの変更があります。現行ソースと本番配信版の一致は未確認です。配布前に実際の利用版と照合してください。
- `02_HANDBOOK_JA.md` は配布前レビュー用の原稿です。未撮影項目を記した制作メモを残しています。完成した配布版と偽って扱わないでください。

## 推奨する完成物

- メンバー用クイックスタート：A4 2ページ
- マネージャー用クイックスタート：A4 2ページ
- 共通＋役割別の詳細マニュアル：A4 約20〜28ページ（読める大きさを優先）
- 編集可能な Markdown と画像一式
- 同内容の PDF（DeepSeek または文書ツールで書き出す場合）

本文は `print.css` と併用できる改ページ指定を含みます。Markdown の変換ツールが HTML/CSS を無視する場合は、そのツールの改ページ指定へ置換してください。

## 添付情報

`capture-evidence.json` は画面ID、役割、画面内文字列を記録しています。掲載画像は検証用の架空データのみです。画像に番号は未描画です。番号を置く位置は `03_AUTHORING_SPEC.md` に定義しています。
